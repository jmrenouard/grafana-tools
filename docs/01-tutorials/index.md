# Tutorials

Guided, reproducible exercises using real repository files to generate, inspect, transform, and package Grafana dashboards.

1. [Tutorial 1: Generate and Export Your First Dashboard](01-generate-and-export-first-dashboard.md) — install dependencies, validate `examples/linux-overview.yaml`, write an archival JSON snapshot, and inspect panel transformations.
2. [Tutorial 2: Build Custom Panels, Transformations, and Run in Docker](02-customize-variables-transformations-and-container.md) — author a custom YAML file with variables and `grafana_transforms.py` rules, verify output JSON, and package the CLI in Docker.
